# 🏢 Control Empleados - Pruebas (`ctrlemp-prueba`)

Repositorio para la gestión y control de empleados, estructurado en arquitectura separada para **Frontend** y **Backend**.

---

## 📂 Estructura del Proyecto

Este repositorio contiene las siguientes aplicaciones y módulos:

* 🎨 **[Frontend](./frontend)**: Aplicación cliente / Interfaz de usuario.
* ⚙️ **[Backend](./backend)**: Servicios API / Lógica de negocio y base de datos.
